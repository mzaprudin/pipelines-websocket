# Архитектура и владение памятью

[English](architecture.md) · [Русский](architecture.ru.md)

FastWebSocketClient соединяет TcpClient, необязательный SslStream, producer с записью в Pipe и ограниченный parser фреймов, читающий Pipe. StdWebSocketClient реализует тот же IFastWebSocket через стандартный клиент .NET.

Нефрагментированное сообщение — заимствованный ReadOnlySequence<byte>. Обработчик использует байты до завершения возвращённого ValueTask; затем parser продвигает Pipe и возвращает память в пул. Данные, нужные после callback, следует скопировать. Сборка фрагментов использует отдельный путь с копированием и аллокацией; размер сообщения ограничен 1 MiB. Порог backpressure Pipe превышает максимальный фрейм, чтобы ожидание целого фрейма не блокировало producer навсегда.

Исходящие фреймы используют scoped ArrayPool rentals, криптографические ключи маски и последовательную отправку. Отдельный gate сохраняет состояние continuation; вызывающий код сериализует отправку целых фрагментированных сообщений. Control-фреймы могут идти между ними. Один владелец управляет соединением, приёмом и завершением; отмена передаётся обоим циклам, задачи наблюдаются при shutdown.

Upgrade проверяет HTTP 101, обязательные токены и accept challenge. TLS использует обычную проверку сертификата, если вызывающий код явно не передал callback. Тесты доверяют только временному локальному сертификату. Таймеры активности данных не учитывают один лишь control-трафик. Переподключение и подписки относятся к приложению. StdWebSocketClient.SendPingAsync выбрасывает NotSupportedException; стандартный keepalive настраивается KeepAliveInterval.

Основная реализация сохраняет ReceiveBufferSize = 65536. Эксперимент с автоматическим размером удаляет только это присваивание в отдельной сборке; это не runtime-настройка основной библиотеки. Send-буфер и алгоритмы приёма сохранены.

PoolRental<T> внутренний для этой сборки; отдельная внутренняя копия есть в ZeroAlloc.Json. Транспорт не требует JSON-реализации, моделей, интернера или фикстур. LoopbackServer и RoundtripSession — вспомогательный код тестов и примера, а не API библиотеки.
