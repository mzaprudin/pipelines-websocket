10 ноября 2026 года: из отдельного чистого git clone выполнены locked restore, Release build, все **70 тестов** (0 ошибок, 0 пропусков) и самостоятельный пример. Сборки завершились без предупреждений. На исходной ревизии прошли все 126 тестов.

Состав публичных типов и объявленных членов сравнен с исходной сборкой; исключение — согласованный internal PoolRental<T>.

Аллокации echo составили 579–581 B/op до и 580–582 B/op после; точные различия сохранены в отчётах. Полный echo не относится к zero-allocation сценариям. Также выполнены 6 streaming-запусков до и 6 после. Self-contained win-x64 генератор собран локально; запуск exe проверяет Windows CI. Исходные 203 Ethernet-файла сохранены побайтно; новых физических измерений не выполнялось.

## Streaming в отдельных процессах

Текущий CLI имеет отдельные роли сервера и приёмника. Локальный и внешний запуск используют один профиль: 128 байт / 20 фреймов / 10 соединений; периодические счётчики относятся только к приёмнику. Раннер сохраняет отдельный PID сервера, шесть свежих команд приёмника, проверенные отчёты и штатный выход сервера.

Локально прошли locked restore, Release build без предупреждений, все **73 C#-теста**, **7 Python-проверок раннера**, пример с проверкой порядка сообщений и все четыре BenchmarkDotNet Dry-сценария. Проверены автоматический запуск локального сервера и явный адрес, очистка после таймаута старта и сбоя генератора, отклонение повреждённых отчётов и штатное завершение. Текущий переносимый win-x64-генератор собран; запуск файла проверяет Windows CI.

Новый полный набор: [20261110T202155Z](../results/local/20261110T202155Z/README.md), измеренная ревизия `4b57e71`. Все четыре echo-сценария и шесть streaming-приёмников завершились успешно. Сохранены разные PID, полные аллокации каждого повтора, samples и штатный выход сервера.
